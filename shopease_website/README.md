# ShopEase E-commerce Website

A responsive multi-page front-end demo inspired by the supplied reference image.

## Pages
- `index.html` — home page
- `products.html` — product catalogue, search, category filters, price range and sorting
- `product-details.html?id=1` — product detail view; change the `id` query parameter to select a product
- `cart.html` — cart quantities, removal, subtotal and shipping estimate
- `about.html` — about page and values
- `contact.html` — contact form with front-end validation/demo response

## Shared files
- `css/style.css` — all common styles, responsive layout and dark mode theme variables
- `js/script.js` — product data and shared interactivity

## Run it
Open `index.html` in a browser. For best results, use VS Code Live Server.
Product photos load from Unsplash and therefore require an internet connection.

## Notes
This is a front-end learning project. The checkout, contact form and newsletter show demo messages; they do not process payments or send emails. Connect a backend/payment provider before using this as a real store.
